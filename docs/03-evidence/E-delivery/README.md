This is **product footage, not the finished three-minute submission video**. It is a scripted,
reproducible walkthrough of the real UI against the real API, in the order of the work plan's
demonstration sequence. Narration, titles and the opening and closing segments (Alfred's 0:00–0:30
and 2:05–3:00) are still to be recorded over it.

Because it is generated by a test, it can be re-cut at any time by editing the spec and re-running
— no manual screen capture to redo when the UI changes.

### What the footage covers

1. Guest entry with the synthetic-data notice, no credentials
2. Worklist, including the overdue filter
3. Child case: equal-weight uncertainty layout
4. Approval refused while information is missing, with the server's reason
5. Source review: SSE extraction, proposals, excerpt highlighted in the note
6. Attendance recorded; the role boundary on closure
7. Closure refused without an evidence reference, then accepted with one
8. Adult case: overdue, rejected referral blocking completion, reassignment
9. Population view: live API suppression, denominators
10. Arabic toggle and RTL mirroring

Nothing in frame is real: no credentials, no real patient data, no real contact details.
