# Decision records

A decision record is for a choice that is **hard to reverse**, **surprising without context**,
and a **genuine trade-off**. Stack selection, data model shape, status vocabulary, auth model,
whether the AI path ships. Not routine clarifications.

Unresolved choices live in [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md) until someone decides.
